# Frontend

React, Vite, TailwindCSS, and shadcn-style local components for the healthcare voice operations dashboard.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Screens

- Dashboard with call statistics, recent calls, and AI system analytics.
- Create Call flow with patient appointment fields and AI system selector.
- Call History with detail pages, transcript, summary, outcome, latency, and live monitor socket.
- Appointment Management for confirmed, rescheduled, scheduled, and failed follow-ups.
